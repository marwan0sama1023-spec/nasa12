# Planetary Exploration

واجهة عربية تفاعلية لاستكشاف سبعة مواقع أرضية مرتبطة بدراسة تضاريس القمر والمريخ. الموقع يميز بين أوصاف صور NASA، ونقاط الموقع التقريبية، والبيانات التي لم تُحمّل أو تُحلل.

## التشغيل

ثبّت الاعتماديات، أنشئ حزمة محرك اللعبة المحلية، ثم شغّل الخادم:

```powershell
npm install
npm run build
npm start
```

ثم افتح `http://localhost:4173`. ملفات Leaflet ومحرك Space Explorer المضمّن موجودة محليًا في `vendor`، لذلك لا تعتمد اللعبة في المتصفح على وجود `node_modules` على خادم النشر. صور الخرائط من NASA GIBS والخط العربي يحتاجان اتصالًا بالإنترنت.

يدعم الموقع العربية والإنجليزية من زر اللغة في الشريط العلوي، ويحفظ اختياره في المتصفح.

## النشر على GitHub Pages

يُبنى محرك اللعبة ويُنشر الموقع تلقائيًا عبر `.github/workflows/pages.yml` عند الدفع إلى `main` أو `master`. من إعدادات المستودع افتح **Settings → Pages** واختر **GitHub Actions** كمصدر النشر. يتضمن ملف النشر الحزمة المحلية وجميع الصور وملفات Leaflet اللازمة، دون `node_modules`.

## الميزات

- واجهة RTL بخلفية عامة من نجوم Canvas فقط، ومشهد رئيسي مستقل للأرض والقمر والمريخ. الحركات تقريب بصري وليست محاكاة فلكية علمية.
- تخفيف الحركة على الأجهزة الأقل قدرة واحترام `prefers-reduced-motion`.
- مساعد محلي يجيب من سجل المواقع ويحفظ سياق المحادثة؛ يعرض مؤشر الكتابة وردًا متدرجًا، ويبدأ أصوات الإشعار تلقائيًا بعد أول تفاعل يسمح به المتصفح. لا يوجد زر صوت أو كتم، ولا يتصل المساعد بنموذج ذكاء اصطناعي أو مصدر بيانات محادثة حي.
- سبعة ملفات مواقع، ومعرض صور، وصفحات القمر والمريخ والمنهجية والمصادر والفريق.
- خريطة Leaflet تفاعلية تبدأ بـNASA Blue Marble لتغطية عالمية واضحة، وتتيح Terra MODIS بتاريخ 14 أكتوبر 2025 وطبقتي المعالم والتسميات من NASA GIBS. العلامات نقاط مرجعية تقريبية على الأرض.
- لعبة Space Explorer ثلاثية الأبعاد بمحرك Three.js وفيزياء Cannon: سبعة عوالم أرضية مستقلة، لكل منها خمسة أنواع عينات افتراضية خاصة بالموقع، ولا يكتمل الموقع قبل جمعها وفحصها. مسار رائد الفضاء منفصل بستة سجلات تعليمية للقمر أو المريخ. بيانات العينات ومراجعها في `game-samples.js`؛ صخور الميدان إجرائية لأن المشروع لا يتضمن نماذج صخرية ثلاثية الأبعاد. التضاريس والصخور تقريب لعب وليست نماذج ارتفاع أو عينات حقيقية. `WASD` للحركة، الماوس للنظر، `Space` للقفز، `Shift` للجري، `E` للتفاعل، `Q` للمسح، و`V` للعربة. الصوت اختياري والتقدم محلي.
- يعرض المريخ خامة عالمية من NASA MARCI على كرة WebGL مضاءة تدور بسلاسة؛ يستخدم صورة هابل والطبقة المتحركة الحالية كاحتياط إذا تعذر WebGL، ويحترم إعداد تقليل الحركة.
- الصور الفضائية ليست بثًا حيًا أو قياسات ميدانية. لا توجد صفحة مخصصة للمصادر في الواجهة الحالية.
- لا يجلب الموقع حاليًا قياسات مناخية أو كيميائية، ولا ينزّل منتجات كوكبية أو يحللها.
- درجات المقارنة والاختيارات تدخلها المجموعة يدويًا؛ لا تنتج المنصة ترتيبًا قبل توفر أدلة مشتركة موثقة.
- صورة الفريق الأصلية هي `صوره عن الفريق.jpeg` في جذر المشروع، وتُستخدم كخلفية معتمة لصفحة الفريق فقط.

## الخريطة

تعتمد طبقات البلاطات على NASA Global Imagery Browse Services (GIBS) عبر WMTS، بنمط Web Mercator المتوافق مع Leaflet. مصدر الطبقة البديلة وطبقتا المعالم والتسميات من NASA GIBS أيضًا. إذا تعذر الاتصال، تظهر رسالة داخل الخريطة وتبقى العلامات وصفحات المواقع متاحة.

يظهر اعتماد مزود الخرائط في عنصر الإسناد المدمج بالخريطة.

## حدود المعلومات

الإحداثيات نقاط مرجعية تقريبية اختيرت للعرض وليست حدود مواقع دراسة أو محطات قياس معتمدة. الصور الفضائية ليست قياسات حرارة أو كيمياء أو نوع صخر.
