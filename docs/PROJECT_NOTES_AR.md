# ملاحظات المشروع

## الفكرة

موقع تفاعلي ثنائي اللغة يستكشف ستة مواقع أرضية تُستخدم لدراسة أسئلة محددة عن تضاريس القمر والمريخ. لا يعرض الموقع هذه البيئات على أنها نسخ مطابقة لعوالم أخرى.

## خريطة الملفات

- `index.html`: مدخل الموقع وملفات التشغيل الأولية.
- `src/app.js`: الصفحات والتنقل والخرائط وسير اللعبة.
- `src/i18n.js`: ترجمة الواجهة والوسوم ورسائل اللعبة المتغيرة.
- `src/game-samples.js`: بيانات العينات الافتراضية، مع حقول عربية وإنجليزية.
- `src/space-game.js`: مصدر محرك Three.js وCannon.
- `src/styles.css`: تنسيقات الموقع واللعبة.
- `vendor/space-game.js`: ناتج بناء محرك اللعبة؛ لا تعدّل هذا الملف يدويًا.
- `assets/`: الصور ورسوم الطاقم والمعدات.
- `vendor/leaflet/`: ملفات Leaflet المحلية.
- `.github/workflows/pages.yml`: بناء ونشر الموقع على GitHub Pages.

## التشغيل

```powershell
npm install
npm run build
npm start
```

ثم افتح `http://localhost:4173`.

## حدود البيانات

الإحداثيات نقاط مرجعية تقريبية وليست حدودًا ميدانية. الصور المدارية لا تمثل قياسات تربة أو حرارة أو كيمياء. مجسمات العينات داخل اللعبة تعليمية وافتراضية، والمراجع تصف المواقع أو المهمات ولا تثبت قياسًا للمجسم نفسه.
